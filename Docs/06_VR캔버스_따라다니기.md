# 오큘러스(헤드셋)를 따라다니는 캔버스

VR 에서는 화면(Screen) 위에 UI 를 그릴 수 없어서, UI 를 **공간에 떠 있는 판(World Space 캔버스)** 으로 만들고, 그 판이 **머리를 부드럽게 따라오게** 합니다.

## 캔버스 오브젝트에 들어 있는 컴포넌트 (CanvasScore / CanvasStart 기준)
| 컴포넌트 | 출처 | 하는 일 | 설정 |
|---|---|---|---|
| **Rect Transform** | Unity | 캔버스 크기·위치 | Width/Height 작게(예 100×100, 400×200), **Scale 0.003~0.01** |
| **Canvas** | Unity UI | UI 를 그리는 판 | **Render Mode: World Space**, **Event Camera: Main Camera** (XR Origin → Camera Offset → Main Camera) |
| **Canvas Scaler** | Unity UI | 글자·이미지 선명도 | Dynamic Pixels Per Unit 을 올리면 글자가 더 또렷 |
| **Graphic Raycaster** | Unity UI | 마우스/일반 클릭 판정 | 에디터에서 마우스로 테스트할 때 |
| **Tracked Device Graphic Raycaster** | XR Interaction Toolkit | **VR 컨트롤러 레이저로 버튼 누르기** | 이게 없으면 VR 에서 버튼이 안 눌림 |
| **Lazy Follow** | XR Interaction Toolkit | **헤드셋을 부드럽게 따라오기** | 아래 표 |
| Canvas Group + EffectPanelOpen | Unity UI + 우리 스크립트 | (CanvasScore) 켜질 때 서서히 나타나기 | |

## Lazy Follow 설정 뜻
| 칸 | 지금 값 | 뜻 |
|---|---|---|
| **Target** | Main Camera | 따라갈 대상 = 헤드셋 |
| **Target Offset** | (0, 0, 6) CanvasScore / (0, 0, 0.5) CanvasStart | 머리 기준 앞으로 6m / 0.5m 위치 |
| Movement Speed | 6 | 따라오는 속도 |
| Snap On Enable | ✅ | 켜지는 순간 바로 제자리로 |
| Position Follow Mode | Follow | 위치 따라오기 |
| Min / Max Distance Allowed | 0.01 / 0.3 | 이 정도 벗어나기 전엔 안 움직임 (조금 고개 돌려도 흔들리지 않게) |
| Rotation Follow Mode | Look At | 항상 나를 바라봄 |
| Min / Max Angle Allowed | 0.1 / 5 | 각도 여유 |
| Time Until Threshold Reaches Max | 3 | 멈춰 있을수록 여유가 커짐 → 덜 흔들림 |

> "Lazy" = 바로 붙어 다니지 않고 **조금 늦게, 부드럽게** 따라옵니다. VR 멀미를 줄입니다.

## 새 VR 캔버스 만드는 순서
1. Hierarchy 우클릭 → **UI → Canvas**
2. Canvas: **Render Mode = World Space**, **Event Camera = Main Camera**
3. Rect Transform: **Width 100, Height 100, Scale 0.003** (다른 캔버스와 비슷하게)
4. Add Component → **Tracked Device Graphic Raycaster** (VR 클릭)
5. 따라다니게 하려면 Add Component → **Lazy Follow** → Target = Main Camera, Target Offset Z = 원하는 거리(m)
6. Ctrl + S

## 따라다니지 않게 하려면
Lazy Follow 체크를 끄거나 제거 → 그 자리에 고정 (CanvasMusic 처럼)
