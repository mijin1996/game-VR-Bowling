# UI · 효과

## 1. VR 캔버스 (헤드셋 따라다니기)
VR은 화면 위에 UI를 못 그려서, **공간에 뜬 판(World Space 캔버스)**이 머리를 따라오게 해요.

| 컴포넌트 | 설정 |
|---|---|
| Canvas | Render Mode **World Space**, Event Camera **Main Camera** |
| Rect Transform | 작게(예 100×100), Scale 0.003~0.01 |
| **Tracked Device Graphic Raycaster** | 없으면 VR 컨트롤러로 버튼이 안 눌림 |
| **Lazy Follow** | Target Main Camera, Target Offset Z = 거리(m) — 조금 늦게 부드럽게 따라와 멀미를 줄임 |

- 고정하고 싶으면 Lazy Follow를 끄기 (CanvasMusic처럼)
- 글자가 옆에 떠 있으면 자식의 Pos X를 0으로

## 2. 떠오르는 점수 숫자 (Floating Text)
핀이 쓰러지면 핀 위에 **+10 → +100**으로 올라가며 떠오르다 사라져요. (에셋: Floating Text Engine Lite)
```
Pin → GameManager.OnPinFallen(머리 위치) → AddScore(100) + EffectNumFlying.Show()
  Billboard(나를 바라봄) + CountUp(0.5초, 10씩) + MoveUp(1.2초, 0.8m) + FadeOut(0.6초 뒤)
```
- 에셋을 아는 곳은 `EffectNumFlying` 하나뿐 → 에셋을 바꿔도 여기만 고치면 됨
- `CountUpBehavior`는 에셋에 없어서 에셋의 틀(`IFloatingBehavior`)을 상속해 직접 만듦
- 씬에 `FloatingTextEngine` 오브젝트 필요, 카메라 Tag는 MainCamera

| 바꿀 것 | 위치 |
|---|---|
| 점수 · 색 | GameManager → Pin Score / Popup Color (알파 255) |
| 올라가는 간격·시간, 높이, 사라지는 때 | `EffectNumFlying.cs` |
