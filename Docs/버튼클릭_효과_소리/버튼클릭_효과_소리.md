# 버튼 클릭 · 효과 · 소리 (어느 프로젝트에나 넣어 쓰는 키트)

> **목표:** 스크립트 5개를 `Assets` 에 넣고, **드래그 앤 드롭만으로** 버튼 클릭 소리 · 눌림 효과 · 파티클 · 판넬 열림/닫힘 효과를 바로 쓰기.
> 다른 스크립트(SoundManager, ButtonManager 등)가 **전혀 없어도** 동작합니다.
> 파일 위치: `Docs/버튼클릭_효과_소리/Scripts/` (BowllyBoll 의 Assets 에는 넣지 않았습니다 — 쓸 프로젝트에 복사해서 사용)

---

## 1. 생각 정리 — "기능" 과 "느낌" 나누기

| 나누는 이유 | |
|---|---|
| **기능** (버튼이 무엇을 하나) | 게임 시작, 다음 레벨, 판넬 열기 … → 게임마다 다름 → **Button 의 On Click 에 내 스크립트 함수를 드래그** (Unity 기본 기능) |
| **느낌** (누를 때 어떤 느낌인가) | 클릭 소리, 눌림 움직임, 파티클 → 어느 게임이든 같음 → **이 키트가 담당** |

이렇게 나누면 기능 코드에 `PlayClick()` 같은 소리 코드를 한 줄도 쓰지 않아도 되고, 새 버튼은 **컴포넌트 하나만 붙이면** 느낌이 다 나옵니다.

```
[버튼 클릭]
   ├─ Button.On Click ──────────► 내 스크립트.StartGame()   ← 기능 (드래그로 연결)
   └─ UIButtonFeedback (자동 연결) ─┬─ UIAudio.Play(클릭 소리)   ← 소리
                                  ├─ 작아졌다 돌아오기         ← 효과(움직임)
                                  └─ UIEffectSpawner.Spawn()   ← 효과(파티클)
[판넬 켜짐]
   └─ UIPanelFeedback (켜질 때 자동) ─ 열림 소리 + 커지며 나타남 + 파티클
[닫기 버튼 On Click → UIPanelFeedback.Close()] ─ 닫힘 소리 + 작아지며 사라짐 → 꺼짐
```

## 2. 파일 5개

| 파일 | 붙이나? | 하는 일 |
|---|---|---|
| `UIButtonFeedback.cs` | **버튼마다** | 클릭 소리 + 눌림 움직임 + 파티클. 같은 오브젝트의 Button/Toggle 에 **자동 연결** |
| `UIPanelFeedback.cs` | **판넬마다** | 열림(켜질 때 자동)/닫힘(`Close()`) 소리 + 움직임 + 파티클 |
| `UIFeedbackDefaults.cs` | 씬에 **하나** (선택) | 기본 클릭/열림/닫힘 소리와 기본 파티클, 전체 UI 소리 크기 → 버튼마다 소리를 안 넣어도 됨 |
| `UIAudio.cs` | 안 붙임 | 소리 재생 창구. 처음 소리 낼 때 숨은 AudioSource 를 스스로 만듦 |
| `UIEffectSpawner.cs` | 안 붙임 | 파티클 꺼내기 (버튼·판넬이 같이 씀) |

- 모두 `namespace UIFeedback` 안에 있어서 다른 프로젝트의 같은 이름 스크립트와 **충돌하지 않습니다.**
- 필요한 것: Unity UI (uGUI). TextMeshPro, 파티클 에셋은 **없어도** 됩니다.

## 3. 넣는 방법 (처음 한 번)
1. `Docs/버튼클릭_효과_소리/Scripts/` 의 `.cs` 5개를 쓸 프로젝트의 **Unity Project 창** `Assets/` 아래(예: `Assets/UIFeedback/`)로 **끌어다 놓기**
2. 컴파일이 끝나면 Add Component 검색에 `UIButtonFeedback`, `UIPanelFeedback`, `UIFeedbackDefaults` 가 나옴

## 4. 쓰는 방법 (드래그 앤 드롭만)

### ① 기본 소리 한 번에 정하기 (추천)
1. Hierarchy 빈 곳 우클릭 → **Create Empty** → 이름 `UIFeedback`
2. **Add Component → UIFeedbackDefaults**
3. 소리 파일을 칸에 끌어다 놓기
   | 칸 | 넣을 것 |
   |---|---|
   | Click Sound | 버튼 클릭 소리 |
   | Open Sound | 판넬 열림 소리 |
   | Close Sound | 판넬 닫힘 소리 |
   | Click Effect / Open Effect | (선택) 파티클 프리팹 |
   | Master Volume | 전체 UI 소리 크기 |

### ② 버튼에 느낌 주기
1. 버튼(또는 토글) 선택 → **Add Component → UIButtonFeedback**
2. 끝. 누르면 소리 + 눌림 + (파티클) 이 나옴
3. 이 버튼만 다른 소리를 쓰려면 **Click Sound** 칸에 소리를 넣기 (기본값보다 우선)

| 칸 | 기본 | 뜻 |
|---|---|---|
| Click Sound | (비움) | 비우면 기본 클릭 소리 |
| Volume | 1 | 이 버튼 소리 크기 |
| Use Motion | ✅ | 눌림 움직임 켜기/끄기 |
| Press Scale | 0.9 | 가장 작아질 때 크기 |
| Duration | 0.15 | 눌렸다 돌아오는 시간(초) |
| Effect Prefab | (비움) | 파티클 (비우면 기본, 그것도 없으면 없음) |
| Effect Scale | 0.3 | 파티클 크기 (World Space UI 는 0.2~0.5) |
| Forward Offset | 0.05 | 파티클을 UI 보다 카메라 쪽으로 얼마나 앞에 |
| Effect Lifetime | 3 | 파티클 자동 삭제 시간 (0 = 안 지움) |

### ③ 버튼 기능 연결 (Unity 기본 방법)
1. 버튼 Inspector → **Button → On Click ( )** → `+`
2. 기능 스크립트가 붙은 오브젝트를 칸에 **드래그** → 함수 선택
   - 판넬 열기: 판넬 오브젝트를 드래그 → `GameObject → SetActive` ✅
   - 판넬 닫기: 판넬 오브젝트를 드래그 → `UIPanelFeedback → Close`
   - 판넬 열기/닫기 한 버튼으로: `UIPanelFeedback → Toggle`
   - 게임 기능: 내 스크립트의 public 함수

### ④ 판넬에 느낌 주기
1. 판넬 선택 → **Add Component → UIPanelFeedback** (CanvasGroup 이 자동으로 같이 붙음)
2. 판넬이 **켜질 때마다** (어느 코드에서 `SetActive(true)` 하든) 열림 소리 + 커지며 나타남
3. 닫기 버튼 On Click 에 `UIPanelFeedback.Close` 연결 → 닫힘 소리 + 작아지며 사라진 뒤 꺼짐

| 칸 | 기본 | 뜻 |
|---|---|---|
| Open Sound / Close Sound | (비움) | 비우면 기본 소리 |
| Duration | 0.25 | 나타나고/사라지는 시간 |
| Start Scale | 0.8 | 시작(끝) 크기 |
| Open Effect | (비움) | 열릴 때 파티클 |

### ⑤ Button 이 아닌 것 (3D 물체, XR 버튼, 다른 이벤트)
그 오브젝트에 `UIButtonFeedback` 를 붙이고, 그 이벤트(예: XR Simple Interactable → Select Entered)에 **`UIButtonFeedback → Play`** 를 연결.

## 5. 기능 스크립트 예시 (게임마다 새로 쓰는 부분)
소리·효과 코드가 하나도 없는 것이 핵심입니다.
```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

// 버튼이 "무엇을 하는지" 만 담당. 각 함수를 버튼의 On Click 에 드래그해서 연결
public class MenuButtons : MonoBehaviour {
    [SerializeField] private GameObject settingsPanel;

    public void StartGame()    { SceneManager.LoadScene("Game"); }
    public void OpenSettings() { settingsPanel.SetActive(true); }   // 열림 효과는 UIPanelFeedback 가 자동으로
    public void QuitGame()     { Application.Quit(); }
}
```

## 6. 멈춤(Time.timeScale = 0) 과 VR
- 움직임은 `Time.unscaledDeltaTime`, 파티클은 `useUnscaledTime` → **멈춤 메뉴 안에서도** 효과가 움직임
- 소리는 2D (거리와 상관없이 같은 크기). VR 에서도 귀에 바로 들림
- World Space Canvas 는 크기가 0.001 같은 아주 작은 값이라, 파티클을 UI 의 자식으로 넣지 않고 **월드에 따로** 꺼냄 → Effect Scale 로 크기 조절
- 파티클은 UI 위치에서 **카메라 쪽으로 Forward Offset 만큼** 앞에 나옴 (UI 뒤에 숨지 않게)

## 7. 안 될 때
| 증상 | 확인 |
|---|---|
| 소리가 안 남 | 버튼 Click Sound 또는 UIFeedbackDefaults 의 Click Sound 칸, Master Volume, 씬에 AudioListener(보통 카메라) 있는지 |
| 눌러도 반응 없음 | Button 의 Interactable ✅, 같은 오브젝트에 Button 이 있는지 (자식에 있으면 그 자식에 붙이기) |
| 파티클이 너무 크거나 안 보임 | Effect Scale (0.2~0.5), Forward Offset, 파티클 프리팹이 스스로 꺼지는 설정인지 |
| 판넬 열림 효과가 첫 번만 소리 없음 | UIFeedbackDefaults 가 씬에 있는지 (먼저 준비되도록 실행 순서 -100 으로 설정돼 있음) |
| 소리가 두 번 남 | 기능 스크립트에도 소리 코드가 남아 있음 → 기능 쪽 소리 코드 지우기 |

## 8. BowllyBoll 의 지금 코드와 비교
| 지금 BowllyBoll | 이 키트 |
|---|---|
| `ButtonManager` 안 `PlayClick()` 10곳 + `PlayOpen()` 2곳 | 소리 코드 없음 → `UIButtonFeedback` / `UIPanelFeedback` 가 냄 |
| `EffectButtonPress` (움직임 + 파티클) | `UIButtonFeedback` (움직임 + 파티클 + **소리**) |
| `EffectPanelOpen` (열림 움직임 + 파티클 + 공용 파티클 함수) | `UIPanelFeedback` (열림/**닫힘** + **소리**) + `UIEffectSpawner` |
| `SoundManager.PlaySFX` 필요 | `UIAudio` 가 스스로 AudioSource 를 만듦 (의존 없음) |

BowllyBoll 에 옮겨 쓰려면: 버튼의 `EffectButtonPress` → `UIButtonFeedback`, 판넬의 `EffectPanelOpen` → `UIPanelFeedback` 로 바꾸고, `ButtonManager` 의 `PlayClick()` / `PlayOpen()` 을 지우면 됩니다. (아직 적용하지 않음)
