## 꼭 지킬 것 3가지
1. **스크립트·프리팹·씬은 Unity Project 창 안에서만 옮기기/이름 바꾸기.** 탐색기나 PowerShell 로 옮기면 `.meta` 연결이 끊겨 "Missing Script" 가 됩니다.
2. **UI 위치는 Scene 창에서 드래그로.** 코드는 위치를 정하지 않습니다 (만들 때 한 번만 가운데에 놓음).
3. **바꾼 뒤에는 Ctrl + S.** 저장 안 하면 다음에 열 때 사라집니다.
