## 꼭 지킬 것 3가지
1. 스크립트·프리팹·씬은 **Unity Project 창 안에서만** 옮기거나 이름 바꾸기 (탐색기로 옮기면 `.meta` 연결이 끊겨 Missing Script)
2. UI 위치는 **Scene 창에서 드래그**로 정하기 (코드는 위치를 정하지 않음)
3. 바꾼 뒤에는 **Ctrl + S**
