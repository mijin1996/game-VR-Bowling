# 게임 규칙과 흐름 (LevelManager · Pin · GameManager)

## 1. 전체 흐름
```
[게임 켜짐]  핀·공·점수판 숨김, [START] 버튼만 보임
    │ START 클릭
    ▼
[레벨 시작]  "LEVEL 1" 팝업, 점수 0, 기회 1번, 핀 10개 고정, 공 소켓에 놓임
    │ 공 던짐
    ▼
[판정]  핀이 다 쓰러지고 1.5초 잠잠해지면 (하나도 안 쓰러지면 8초 뒤)
    ├ 목표 점수 도달 ─────────▶ NICE JOB! → 클리어 판넬 (LEVEL CLEAR! + Score) → [NEXT LEVEL] → 다음 레벨
    ├ 0개      → MISS          ─┐
    ├ 1~4개    → (문구 없음)    ├ 기회 1 사용
    ├ 5~6개    → GREAT!  기회 +1 │
    ├ 7개 이상 → GORGEOUS! 기회 +2┘
    │
    ├ 기회 남음 → 핀 10개 다시 세우고 계속 던지기
    └ 기회 0   → FAIL (MISS 로 끝났으면 FAIL 문구 없이 MISS 만) → 실패 판넬 (LEVEL FAILED + Score)
                  → [NEXT LEVEL] 누르면 같은 레벨을 점수 0 부터 다시
```
- 레벨이 끝날 때마다 랭킹에 저장 (같은 판은 덮어쓰기)
- 10단계 클리어 → "ALL CLEAR!" 판넬

## 2. 조절할 수 있는 숫자 (LevelManager Inspector)
| 칸 | 기본값 | 뜻 |
|---|---|---|
| Max Level | 10 | 마지막 레벨 |
| Score Per Level | 500 | 목표 = 레벨 × 이 값 (1단계 500, 2단계 1000 …) |
| Start Chances | 1 | 레벨 시작 때 기회 |
| Bonus For 5 | 1 | 5~6개 쓰러뜨리면 더 주는 기회 (GREAT) |
| Bonus For 7 | 2 | 7개 이상이면 더 주는 기회 (GORGEOUS) |
| Settle Time | 1.5 | 마지막 핀이 쓰러지고 이만큼 잠잠하면 판정 |
| Miss Time | 8 | 던진 뒤 이만큼 지나도 0개면 MISS |

점수: GameManager **Pin Score** (기본 100) = 핀 하나당 점수.

## 3. 핀 한 개의 일생 (Pin.cs)
```
생김/다시 세움 → [고정] isKinematic = 켬 → 절대 저절로 안 움직임
                    │ 공(또는 움직이는 핀)이 "핀 크기 + 5cm" 안으로 들어옴 (매 물리 프레임 검사)
                    ▼
               [풀림] isKinematic = 끔 → 물리대로 쓰러짐
                    │ 머리 Trigger 가 Floor 태그에 닿음  또는  45도 이상 기울어짐
                    ▼
               [쓰러짐] 점수 +100, 소리, 떠오르는 숫자 (한 핀은 한 번만)
```
조절: Pin 컴포넌트 **Unfreeze Margin**(풀리는 거리, 0.05m), **Fallen Angle**(쓰러짐 각도, 45도)

## 4. 공 한 개의 일생 (Ball.cs · BallSpawner.cs)
```
소켓에 놓임 (Sleep, 속도 0)
  │ 손으로 잡음 → 들고 있는 동안은 절대 회수 안 함
  │ 놓음
  ├ 소켓에서 0.5m 안 → "다시 놓기" → 소켓 자리로 복귀
  └ 0.5m 밖 → "던짐" (Thrown 알림 1번)
        │ BallSpawner: 0.5초 뒤 빈 소켓에 새 공 / LevelManager: 판정 시작
        ▼
     회수 조건: 높이 -10 아래 / 소켓에서 30m 이상 / 놓은 지 30초
        → 꺼서 창고에 보관 (다음에 재사용)
```

## 5. 화면 문구 (가운데 팝업)
| 문구 | 언제 | 소리 칸 (SoundManager) |
|---|---|---|
| LEVEL n | 레벨 시작 | 없음 |
| MISS | 0개 | Miss Clip |
| GREAT! | 5~6개 | Great Clip |
| GORGEOUS! | 7개 이상 | Gorgeous Clip |
| NICE JOB! | 목표 점수 도달 | Nice Job Clip |
| FAIL | 기회를 다 쓰고 목표 미달 (MISS 로 끝난 경우 제외) | Fail Clip |

팝업이 나오는 동안 레벨 글자·점수 글자는 잠깐 숨겨집니다 (겹쳐 보이지 않게).
