# 리듬 천장 효과 (rhthem.cs)

음악이 나오는 동안 천장 효과(조명·빛나는 판)가 **박자에 맞춰 랜덤으로 부드럽게 꺼졌다 켜지며** 리듬을 눈으로 느끼게 합니다.

## 1. 설정 순서
1. Hierarchy 우클릭 → **Create Empty** → 이름 `Rhythm`
2. Add Component → **rhthem**
3. **Ceiling Effects** 칸에 천장 효과 오브젝트 끌어다 넣기 (부모 하나만 넣어도 자식까지 전부)
4. 곡의 **BPM** 을 알면 BPM 칸에 (예: 120). 모르면 **0** → 소리를 듣고 자동으로 박 찾기
5. Ctrl + S → Play → 토글로 음악 켜기
6. Console 확인: `[rhthem] 깜빡일 대상 ○○개 준비 완료` 가 나오면 정상

## 2. Inspector 칸
| 칸 | 기본값 | 뜻 |
|---|---|---|
| Music | (비움) | 들을 AudioSource. 비우면 SoundManager 의 BGM |
| Ceiling Effects | | 깜빡일 오브젝트들 |
| **Song Bpms** | (비움) | **노래별 BPM**. SoundManager Songs 와 같은 순서 (Element 0 = 1번 노래). 0 이면 그 노래는 자동 |
| Bpm | 0 | 모든 노래 공통 BPM. 0 = 자동 |
| Beats Per Bar | 4 | 한 마디의 박 수 (4/4 박자 = 4, 3/4 = 3) |
| Beat Offset | 0 | 곡 시작과 첫 박 사이 시간(초). BPM 을 넣었을 때 박이 살짝 어긋나면 조절 |
| Sensitivity | 1.5 | (자동) 저음이 평소보다 얼마나 튀어야 "쿵" 으로 볼지. 낮추면 더 잘 잡음 |
| Bass Max Hz | 150 | (자동) 이 주파수 아래 소리(드럼·베이스)만 들음 |
| Bpm Range | 70 ~ 180 | (자동) 찾을 빠르기 범위 |
| Off Level | 0.1 | 꺼졌을 때 밝기 (0 = 완전히 꺼짐) |
| On Chance | 0.5 | 일반 박에서 켜지는 비율 |
| **Fade Portion** | 0.35 | 한 박 중 밝기가 바뀌는 데 쓰는 비율. 작으면 톡톡 끊기고, 크면 부드럽게 |
| Fade Speed | 8 | 아직 빠르기를 모를 때(곡 처음 몇 초) 밝기 변하는 속도 |

## 3. 어떻게 만들었나 (원리)

### ① 깜빡일 대상 모으기 (시작할 때 한 번)
넣은 오브젝트와 자식들에서
- **Light** → `intensity`(밝기) 를 조절
- **Renderer** → 재질의 **발광색(_EmissionColor)** 밝기를 조절. 발광이 없는 재질이면 기본색(_BaseColor) 밝기
각각의 **원래 밝기**를 기억해 둡니다 (나중에 원래대로 돌려놓기 위해).

### ② 박 찾기 — 순서
1. **노래별 BPM** (Song Bpms, 지금 고른 노래 번호의 칸) → 2. **공통 BPM** → 3. **자동**

**BPM 을 알 때 (정확)**
```
한 박 길이 = 60 ÷ BPM          (120 BPM → 0.5초, 90 BPM → 0.67초)
지금 몇 번째 박 = (음악 재생 시간 - Beat Offset) ÷ 한 박 길이
번호가 바뀌는 순간 = 새 박
```

**BPM = 0 일 때 (자동으로 곡의 빠르기 알아내기)**
```
1) 저음 세기 = 스펙트럼(GetSpectrumData)에서 Bass Max Hz 아래 칸들의 합   ← 드럼·베이스만
2) 변화량 = 저음 세기가 지난 프레임보다 "커진" 양 (줄어든 건 0)
3) 평소 수준 = 최근 1.5초 변화량의 평균과 흔들림
   변화량 > 평균 + Sensitivity × 흔들림  →  "쿵"
4) "쿵" 사이 간격들을 최근 16개 모아서
   - 2박·4박을 건너뛴 간격은 반으로, 반 박 간격은 두 배로 접어서 Bpm Range 안으로
   - 가운데 값(중앙값) = 한 박 길이   ← 튀는 값에 흔들리지 않음
5) 한 박 길이를 알면 그 간격으로 박을 친다 (쿵을 놓쳐도 박자가 계속 이어짐)
   새 "쿵" 이 들리면 박 위치를 그 순간으로 살짝 당겨 맞춤 (곡과 어긋나지 않게)
```
그래서 **빠른 곡은 빠르게, 느린 곡은 느리게** 깜빡입니다. 노래를 바꾸면 처음부터 다시 잽니다 (곡 시작 후 몇 초 동안은 "쿵" 마다 깜빡이다가 빠르기를 알면 박자대로).

### ③ 박마다 할 일
- 마디의 **첫 박**(4/4 면 1, 5, 9…번째) → **전부 밝게** "쿵"
- 나머지 박 → 각 효과마다 **On Chance 확률로 켜기, 아니면 Off Level 로 어둡게** (랜덤)
→ 첫 박에 확 밝아지고 2·3·4박에 랜덤으로 반짝여서 박자감이 생깁니다.

### ④ 부드럽게 바꾸기 — 빠르기에 맞춰
박에서는 "가려는 밝기(goal)" 만 정하고, 매 프레임 지금 밝기를 goal 쪽으로 옮깁니다.
```
바뀌는 시간 = 한 박 길이 × Fade Portion       (120 BPM → 0.5 × 0.35 ≈ 0.18초)
지금 밝기 = Lerp(지금 밝기, 목표 밝기, 1 - e^(-3 × 프레임 시간 ÷ 바뀌는 시간))
```
빠른 곡은 한 박이 짧아서 밝기도 빨리 바뀌고, 느린 곡은 천천히 바뀝니다. 프레임 속도(72/90/120Hz)가 달라도 같은 속도입니다.

### ⑤ 원래대로
- 음악이 멈추면 → 모두 원래 밝기로 서서히
- rhthem 이 꺼지면 → 즉시 원래 밝기

### ⑥ 재질을 직접 바꾸지 않는 이유
`MaterialPropertyBlock` 으로 **그 오브젝트에만** 밝기를 덮어씌웁니다. 재질 파일 자체는 바뀌지 않아서, Play 를 끄면 원래대로이고 같은 재질을 쓰는 다른 오브젝트에도 영향이 없습니다.

## 4. 안 될 때
| Console / 증상 | 원인 | 해결 |
|---|---|---|
| `Ceiling Effects 칸이 비어 있어요` | 대상 없음 | 오브젝트 넣기 |
| `Light 나 Renderer 가 없어서…` | 넣은 게 빈 부모이거나 파티클만 있음 | 빛나는 본체(조명/메쉬)가 있는 오브젝트 넣기 |
| 아무 메시지도 없음 | rhthem 이 씬에 없음 | 1번 설정 순서대로 붙이기 |
| 깜빡이는데 박이 안 맞음 / 속도가 일정함 | 자동 모드가 곡 빠르기를 잘못 잡음 (저음이 약한 곡) | **Song Bpms 에 그 노래 BPM 넣기** + Beat Offset 조절. 또는 Sensitivity 낮추기 |
| 너무 정신없음 | | Fade Portion 올리기, On Chance 올리기, Off Level 올리기 |
| 효과가 약함 | Bloom 이 꺼져 있음 | 루트 폴더 `URP_형광효과_Bloom_설정가이드.md` |
