# 음악 · 천장 조명

## 1. 노래 선택 · 재생
| 누가 | 하는 일 |
|---|---|
| 토글(musciOnOff) | 켜기/끄기만 → `SoundManager.ToggleBGM()` |
| `SongListUI` | 노래 고르기만 → `SoundManager.PlaySong(번호)`, 고른 버튼 하늘색 |
| `SoundManager` | 실제 재생 + "노래 바뀜(SongChanged)" 알림 |

- 시작할 때 음악은 자동으로 안 나옴 (Play On Awake ❌, Loop ✅)
- 음악이 켜져 있으면 고른 노래를 처음부터, 꺼져 있으면 노래만 바꿔 둠
- 노래 추가: `Assets/Music`에 넣기 → SoundManager **Songs**에 추가 → 버튼이 모자라면 SongList 프리팹 버튼 복사

## 2. Beat Sage 천장 조명 (`BeatSageLights`, 사용 중)
[beatsage.com](https://beatsage.com)의 AI가 노래에서 리듬을 찍은 맵 파일대로 천장을 깜빡여요.
```
맵의 노트 시간(박) × 60 ÷ 120(BPM) = 초 → 음악 시간이 지나면 깜빡
  양손 노트(강한 박) → 전부 밝게 / 노트 1개 → 50% 확률로 일부만
  조용한 구간(앞뒤 2초 노트 없음) → 원래 밝기
```
**새 노래 추가 순서**
1. Beat Sage에서 Expert · Standard로 받아 폴더째 `Assets/Music`에 넣기
2. `Expert.dat`, `Info.dat`를 **`.json`으로 복사** (Unity는 `.dat`를 못 읽음)
3. Hierarchy **RhythmBeatSaga → Song Maps** `+` → Song(mp3), Beat Map(Expert.json), Info(Info.json)

| 조절 | 칸 |
|---|---|
| 깜빡임이 늦음/빠름 | Offset (늦으면 +, 빠르면 −, 0.05씩) |
| 덜 정신없게 / 더 화려하게 | On Chance↓·Hold Portion↑ / Off Level↓·On Chance↑ |
| 노트 양 | Hard.json(적게) / ExpertPlus.json(많게) |
