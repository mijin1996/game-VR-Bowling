# 게임 규칙 (현재 버전)

> 2026-10-18 기준 실제 코드(`LevelManager.cs`, `ButtonManager.cs`)와 똑같이 정리한 규칙입니다.
> 예전 규칙 문서 [03_게임규칙_흐름.md](03_게임규칙_흐름.md) 는 GREAT/GORGEOUS 시절 내용이라 **이 문서가 최신**입니다.

---

## 1. 한 판의 흐름

```
[게임 시작] 버튼 대기 (로비)
   │  핀·공·점수판·카운트다운 모두 숨김
   ▼
[게임 시작] 누름
   ▼
LEVEL 1 팝업 → 점수 0, 기회 1번, 핀 4세트·공 보관대 3개 새로 채움, 30초 카운트다운 시작
   ▼
공 던지기 ──► 결과 판정 (아래 2번 표) ──► 다음 기회 / 클리어 / 실패
   ▼
결과 판넬 (clearpanel) : NEXT / RESTART / QUIT
```

---

## 2. 공 한 번 던질 때마다 판정

핀이 다 쓰러지고 **1.5초** 동안 더 안 쓰러지면 판정합니다. (하나도 안 쓰러지면 **8초** 뒤 판정)

| 결과 | 화면 글자 | 소리 | 효과 | 기회 | 핀 |
|---|---|---|---|---|---|
| **목표 점수 도달** | NICE JOB! | Nice Job Clip | 글자 팝업 | – | 숨기고 **클리어 판넬** |
| **0개** | MISS | Miss Clip | 글자 팝업 + Miss Effect(펑) | **-1** | 기회가 남으면 다시 세움 |
| **1개 이상** | ONE MORE! | One More Clip | 글자 팝업 + One More Effect(별) | **-1 +1** (그대로 유지) | 다시 세움 |
| 1개 이상인데 ONE MORE 를 이미 **3번** 받음 | (없음) | – | – | **-1** | 기회가 남으면 다시 세움 |
| **기회 0** + 목표 미달 | FAIL (마지막이 MISS 면 MISS 만) | Fail Clip | 글자 팝업 | – | 숨기고 **실패 판넬** |
| **30초 안에 못 던짐** | MISS | Miss Clip | 글자 팝업 | – | 숨기고 **실패 판넬** |

- 핀 1개 = **100점** (`GameManager` → Pin Score)
- 목표 점수 = **레벨 × 500** (1레벨 500, 2레벨 1000 … 10레벨 5000)
- ONE MORE 는 **목표 점수 전까지만** 나옵니다. 목표를 넘긴 투구는 몇 개를 쓰러뜨렸든 바로 NICE JOB.
- MISS 와 FAIL 은 **동시에 나오지 않습니다.**

### 예시 (1레벨, 목표 500)
| 투구 | 쓰러짐 | 점수 | 결과 | 남은 기회 |
|---|---|---|---|---|
| 1 | 3개 | 300 | ONE MORE (1/3) | 1 |
| 2 | 0개 | 300 | MISS | 0 → 실패 판넬 |

| 투구 | 쓰러짐 | 점수 | 결과 |
|---|---|---|---|
| 1 | 2개 | 200 | ONE MORE (1/3) |
| 2 | 3개 | 500 | **NICE JOB → 클리어 판넬** |

## 3. 레인 4개 (핀 세트 4개)

- 핀 세트: `핀`, `핀 (1)`, `핀 (2)`, `핀 (3)` — 각자 핀 10개
- 어느 레인을 쳐도 판정은 같고, 판정이 끝나면 **4세트 모두** 다시 섭니다.
- 공 보관대: `소켓`, `소켓 (1)`, `소켓 (2)` — 어느 보관대 공을 던져도 판정됩니다.

### 레인 글자 (각 핀 세트 아래)
| 글자 | 보이는 것 |
|---|---|
| 맞힌 핀 갯수 보임 text | 그 레인에서 쓰러진 개수 `5 pin` (던지는 동안 실시간으로 올라감, 다음 공을 던질 때까지 유지) |
| 카운트다운 text | 남은 시간 `30, 29 …` (첫 투구 전에는 4개 레인 모두, 맞힌 뒤에는 **맞힌 레인에만**) |

---

## 4. 제한 시간
- **기회마다 30초** (ONE MORE 로 받은 기회도 매번 30초부터)
- 공을 던지면 멈추고, 판정이 끝나면 다음 기회의 30초가 시작
- ⏸ 멈춤 메뉴가 열려 있으면 같이 멈춤
- 0초 → MISS → 실패 판넬 (남은 기회가 있어도 끝)

---

## 5. 결과 판넬 (clearpanel) 버튼

| 버튼 | 클리어 (LEVEL CLEAR / ALL CLEAR) | 실패 (LEVEL FAILED) |
|---|---|---|
| **NEXT** | 다음 레벨 | 넘어가지 않음 — Score 자리에 **안내 문구 2초** (ButtonManager → Not Cleared Message) |
| **RESTART** | 같은 레벨 처음부터 (점수 0, 기회·ONE MORE 횟수 초기화) | 같음 |
| **QUIT** | 게임을 끄지 않고 **로비**(게임 시작 대기 화면)로 | 같음 |

- 결과 판넬이 열리면 판넬 열림 소리(Open Clip), 점수판·레벨 글자는 숨김
- 판넬이 열릴 때 점수는 **랭킹에 저장**

### ⏸ 멈춤 메뉴 (CanvasMusic > PauseMenu)
| 버튼 | 하는 일 |
|---|---|
| ⏸ | 열기/닫기 (열려 있을 때 다시 누르면 닫힘). 열려 있는 동안 게임 시간 멈춤 |
| RESUME | 닫고 계속 |
| RANKING | 랭킹 열기 — **멈춤이 풀리고 플레이 계속 가능** (랭킹 보는 동안 점수판은 숨김) |
| RESTART | 저장 후 씬 다시 불러오기 (처음부터) |
| QUIT | 저장 후 게임 종료 |
- 게임 시작 전(로비)에 ⏸ 를 열면 [게임 시작] 버튼이 숨고, 닫으면 다시 보임

---

## 6. 랭킹
- 저장 시점: 레벨 클리어/실패, QUIT/처음부터/종료, 헤드셋 벗기
- **한 판 = 한 줄** (같은 판은 점수·시각이 최신으로 덮어써짐), 0점은 저장 안 함
- 정렬: 점수 높은 순 → 같으면 레벨 높은 순. 10개 보관, 화면에는 5개
- 날짜: 저장 순간의 기기 시각 `10/18 14:20`
- 랭킹창이 열려 있는 동안 기록이 저장되면 **바로 다시 그려짐**

## 7. 숫자 바꾸는 곳 (LevelManager Inspector)

| 칸 | 기본 | 뜻 |
|---|---|---|
| Max Level | 10 | 마지막 레벨 |
| Score Per Level | 500 | 레벨당 목표 점수 증가량 |
| Start Chances | 1 | 레벨 시작 기회 |
| Bonus For 5 | 1 | ONE MORE 때 더 주는 기회 |
| Min Pins For One More | 1 | 몇 개 이상 맞혀야 ONE MORE |
| Max One More Per Level | 3 | 레벨당 ONE MORE 최대 횟수 |
| Settle Time | 1.5 | 마지막 핀이 쓰러지고 판정까지 기다리는 시간 |
| Miss Time | 8 | 하나도 안 쓰러질 때 판정까지 기다리는 시간 |
| Throw Time Limit | 30 | 기회마다 제한 시간 |
| One More Message | ONE MORE! | ONE MORE 글자 |
