# 음악 선택과 재생

> 노래 목록에서 곡을 고르고, 토글로 켜고 끄는 구조. (예전 문서 [07_음악_노래목록.md](07_음악_노래목록.md) 의 최신판)
> 천장 조명이 노래에 맞춰 깜빡이는 부분은 [15_BeatSage_적용.md](15_BeatSage_적용.md)

## 1. 역할 나누기

| 누가 | 하는 일 | 위치 |
|---|---|---|
| **List Item Toggle** | 음악 **켜기 / 끄기만** → `SoundManager.ToggleBGM()` | CanvasMusic > musciOnOff |
| **SongList** (SongListUI) | 어떤 노래인지 **고르기만** → `SoundManager.PlaySong(번호)` | CanvasMusic > SongList (프리팹) |
| **SoundManager** | 실제 재생 (Bgm Audio Source 하나로) + "노래 바뀜" 알림 | SoundManager |
| **BeatSageLights** | 지금 나오는 노래에 맞는 Beat Sage 맵으로 천장 깜빡임 | RhythmBeatSaga |

```
[노래 버튼 2 클릭] ──► SongListUI ──► SoundManager.PlaySong(1)
                                            ├─ bgmAudioSource.clip = Songs[1]
                                            ├─ (음악이 켜져 있었으면) Play()
                                            └─ SongChanged(1) 알림 ──► SongListUI: 2번 버튼 하늘색
                                                                 └─► BeatSageLights: 맵 다시 고름
[토글 클릭] ──► SoundManager.ToggleBGM() ──► 재생 중이면 Pause(), 아니면 Play()
```

---

## 2. 동작 규칙
- 게임을 켜도 **음악은 자동으로 나오지 않음** (Bgm Audio Source 의 Play On Awake ❌)
- 노래 버튼을 누르면
  - 음악이 **켜져 있으면** → 그 노래로 바꿔 **처음부터** 재생
  - 음악이 **꺼져 있으면** → 노래만 바꿔 두고, 토글을 켜면 그 노래
- 아직 고른 노래가 없는데 토글을 켜면 → **Songs 의 첫 곡**
- 토글로 끄면 `Pause()` → 다시 켜면 **이어서** 재생
- 지금 고른 노래 버튼은 **하늘색** (SongListUI → Selected Color)
- 버튼 글자 = **노래 파일 이름**. Songs 칸이 비어 있으면 버튼에 `(empty)` 가 보이고 눌리지 않음

## 3. 코드

### SoundManager.cs
```csharp
public AudioClip[] songs;                              // 노래 목록 (Inspector)
public int CurrentSongIndex { get; private set; } = -1;
public event System.Action<int> SongChanged;          // 고른 노래가 바뀜

// 토글: 켜기 / 끄기만
public void ToggleBGM() {
    if (bgmAudioSource.isPlaying) { bgmAudioSource.Pause(); return; }
    if (bgmAudioSource.clip == null && songs != null && songs.Length > 0) {
        bgmAudioSource.clip = songs[0];                // 고른 노래가 없으면 첫 곡
        CurrentSongIndex = 0;
        SongChanged?.Invoke(0);
    }
    bgmAudioSource.Play();
}

// 노래 목록에서 i 번째 고르기
public void PlaySong(int index) {
    if (songs == null || index < 0 || index >= songs.Length || songs[index] == null) return;
    bool wasOn = bgmAudioSource.isPlaying;
    bgmAudioSource.Stop();
    bgmAudioSource.clip = songs[index];
    CurrentSongIndex = index;
    if (wasOn) bgmAudioSource.Play();                  // 켜져 있었을 때만 바로 재생
    SongChanged?.Invoke(index);
}
```

### SongListUI.cs (SongList 프리팹)
```csharp
private void Start() {
    for (int i = 0; i < songButtons.Count; i++) {
        bool hasSong = sm.songs != null && i < sm.songs.Length && sm.songs[i] != null;
        label.text = hasSong ? sm.songs[i].name : "(empty)";   // 버튼 글자 = 파일 이름
        b.interactable = hasSong;
        int index = i;                                          // 버튼마다 자기 번호 기억
        b.onClick.AddListener(() => SoundManager.instance.PlaySong(index));
    }
    sm.SongChanged += Highlight;                                // 고른 버튼 색 바꾸기
}
```
- 버튼 연결은 **코드가 Start 에서** 함 → Inspector 의 On Click 에 따로 넣지 않아도 됨
- SongListUI 는 "노래가 바뀌었다"는 **알림(이벤트)** 만 듣고 색을 바꿈 → SoundManager 는 버튼을 몰라도 됨

## 5. 노래 추가 / 교체 순서
1. 노래 파일(mp3/wav/ogg)을 Project 창 `Assets/Music` 에 끌어다 넣기
2. **SoundManager → Songs** 에서 칸 수를 늘리고 노래를 끌어다 넣기
3. 버튼이 모자라면 SongList 프리팹 안의 버튼을 복사하고 **SongListUI → Song Buttons** 목록에 추가
4. 천장 깜빡임도 맞추려면 [15_BeatSage_적용.md](15_BeatSage_적용.md) 의 "새 노래 추가"
5. Ctrl + S

## 6. 안 될 때
| 증상 | 확인 |
|---|---|
| 버튼이 `(empty)` | Songs 의 같은 번호 칸이 비어 있음 |
| 버튼을 눌러도 소리 없음 | 토글이 꺼져 있음 (노래만 바뀌어 있음) → 토글 켜기 |
| 켜자마자 음악이 나옴 | Bgm Audio Source 의 Play On Awake 체크 해제 |
| 노래가 끝나고 멈춤 | Bgm Audio Source 의 Loop 체크 |
