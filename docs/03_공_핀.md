# 공 · 핀

## 1. 핀 (`Pin`, `PinSpawner`)
```
놓임/다시 세움 → [고정] isKinematic 켬 (저절로 안 움직임)
  → 공이 "핀 크기 + 5cm" 안으로 오면 [풀림] 물리대로 쓰러짐
  → 머리가 Floor 태그에 닿거나 45도 넘게 기울면 [쓰러짐] +100점, 소리, 숫자 (한 번만)
```
- 다시 세우기는 LevelManager가 판정을 끝낸 뒤 `Pin.ResetAllPins()`로 함
- 조절: Pin → Unfreeze Margin(0.05m), Fallen Angle(45도)

## 2. 공 (`Ball`, `BallSpawner`)
```
소켓에 놓임 → 손으로 잡음 (들고 있는 동안은 회수 안 함) → 놓음
  ├ 소켓에서 0.5m 안: 소켓 자리로 복귀
  └ 0.5m 밖: 던짐 → 0.5초 뒤 빈 소켓에 새 공
회수: 높이 -10 아래 / 소켓에서 30m 이상 / 놓은 지 30초 → 꺼서 창고에 보관 후 재사용
```

## 3. 프리팹 · 씬 설정 체크리스트
| 대상 | 확인 |
|---|---|
| 공 프리팹 | Scale **양수**(약 0.22), Rigidbody, Sphere Collider, XR Grab Interactable, Ball |
| 핀 프리팹 | Rigidbody, 몸통 Collider, 머리 Trigger Collider, Pin |
| 바닥 | 레인·핀 뒤 바닥 Tag = **Floor** |
| BallSpawner | Prefabs(공 프리팹들), Sockets(XR Socket Interactor), 소켓 간격 약 0.3m |
| PinSpawner | Prefabs(핀), Spawn Points(핀 자리 10곳), Scale 1 |
| 씬 | 원래 놓여 있던 공·핀은 지우기 (스포너가 만들기 때문) |

## 4. 자주 나는 문제
| 증상 | 해결 |
|---|---|
| 공이 한쪽에 뭉침 | 씬의 원래 공 지우기, Scale 양수, 소켓 간격 넓히기 |
| 점수가 안 오름 | 바닥 Tag Floor, 핀에 Rigidbody |
| 스크립트가 안 붙음 | 파일 이름 = 클래스 이름 |
