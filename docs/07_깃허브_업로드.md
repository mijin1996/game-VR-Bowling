# 깃허브 업로드

## 1. 올리는 것 / 안 올리는 것
| 올림 | 안 올림 (`.gitignore`) |
|---|---|
| `Assets/` (**`.meta` 포함 필수**), `Packages/manifest.json`, `packages-lock.json`, `ProjectSettings/` | `Library/`, `Temp/`, `Logs/`, `UserSettings/`, `.utmp/`, `*.csproj`, `*.sln(x)`, `*.apk`, 빌드 백업 폴더 |

- `.meta`가 빠지면 씬의 스크립트·소리·재질 연결이 끊겨요
- 외부 에셋(Bowling Club, Floating Text 등)은 공개 배포 금지 라이선스가 많아서 **Private 저장소** 권장

## 2. 수정사항 올리기
```bash
git pull               # 유니티 켜기 전에 최신 받기
git status
git add -A
git commit -m "바꾼 내용 한 줄"
git push
```
- 올리기 전 유니티에서 **Ctrl + S** (씬은 저장 안 하면 안 올라감)

## 3. 새 컴퓨터에서 받기
`git clone` → Unity Hub **Add project from disk** → 프로젝트와 같은 Unity 버전으로 열기 (처음엔 Library 생성으로 오래 걸림)
