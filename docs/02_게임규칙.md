# 게임 규칙

## 1. 한 판의 흐름
```
로비: [게임 시작] 버튼만 보임 (핀·공·점수판 숨김)
 → LEVEL 1: 점수 0, 기회 1번, 핀 4세트·공 보관대 3개, 30초 카운트다운
 → 공 던지기 → 판정 → 다음 기회 / 클리어 / 실패
 → 결과 판넬: NEXT / RESTART / QUIT
```

## 2. 판정 (핀이 다 쓰러지고 1.5초 뒤, 하나도 안 쓰러지면 8초 뒤)
| 결과 | 글자 | 기회 |
|---|---|---|
| 목표 점수 도달 | NICE JOB! | → 클리어 판넬 |
| 1개 이상 (목표 전, 레벨당 3번까지) | ONE MORE! | 그대로 (-1 +1) |
| 1개 이상인데 ONE MORE 3번 다 씀 | (없음) | -1 |
| 0개 | MISS | -1 |
| 기회 0 + 목표 미달 | FAIL (마지막이 MISS면 MISS만) | → 실패 판넬 |
| 30초 안에 못 던짐 | MISS | → 실패 판넬 |

- 핀 1개 = 100점, 목표 점수 = 레벨 × 500 (최대 10레벨)
- 레인 4개 중 어디를 쳐도 판정은 같고, 판정 후 4세트 모두 다시 섬
- 레인마다 쓰러진 개수(`5 pin`)와 남은 시간이 표시됨

## 3. 결과 판넬 · 멈춤 메뉴
| 버튼 | 하는 일 |
|---|---|
| NEXT | 클리어 → 다음 레벨 / 실패 → 넘어가지 않고 안내 문구 2초 |
| RESTART | 같은 레벨 처음부터 |
| QUIT | 로비로 |
| ⏸ (멈춤) | RESUME / RANKING / RESTART / QUIT, 열려 있는 동안 시간 멈춤 |

- 결과 판넬이 열리면 핀·공·레벨 글자·점수판을 숨기고, NEXT를 누르면 다시 보임

## 4. 랭킹
- 레벨 클리어·실패, 종료할 때 저장 / 한 판 = 한 줄, 0점은 저장 안 함
- 점수 높은 순(같으면 레벨 높은 순), 10개 보관·화면엔 5개, 열려 있으면 바로 갱신

## 5. 숫자 바꾸는 곳 (LevelManager Inspector)
| 칸 | 기본 |
|---|---|
| Max Level / Score Per Level / Start Chances | 10 / 500 / 1 |
| Max One More Per Level / Min Pins For One More | 3 / 1 |
| Settle Time / Miss Time / Throw Time Limit | 1.5 / 8 / 30 |
