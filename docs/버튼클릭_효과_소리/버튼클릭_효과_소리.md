# 버튼 클릭 · 효과 · 소리 키트

다른 프로젝트에 `Scripts/`의 `.cs` 5개를 넣고 **컴포넌트만 붙이면** 버튼 소리·눌림·파티클·판넬 열림/닫힘이 생겨요. (다른 매니저 스크립트 없이 동작, `namespace UIFeedback`)

## 생각: "기능"과 "느낌" 나누기
- **기능**(게임 시작, 판넬 열기…): 게임마다 다름 → Button의 On Click에 내 함수 연결
- **느낌**(소리, 눌림, 파티클): 어느 게임이든 같음 → 이 키트가 담당 → 기능 코드에 소리 코드가 필요 없음

## 파일
| 파일 | 붙이는 곳 | 하는 일 |
|---|---|---|
| `UIButtonFeedback` | 버튼마다 | 클릭 소리 + 눌림 + 파티클 (Button/Toggle에 자동 연결) |
| `UIPanelFeedback` | 판넬마다 | 켜지면 열림 효과, `Close()`로 닫힘 효과 |
| `UIFeedbackDefaults` | 씬에 하나 (선택) | 기본 클릭/열림/닫힘 소리·파티클, 전체 볼륨 |
| `UIAudio`, `UIEffectSpawner` | 안 붙임 | 소리 재생(AudioSource 자동 생성), 파티클 꺼내기 |

## 쓰는 법
1. 빈 오브젝트 `UIFeedback` → `UIFeedbackDefaults` 붙이고 기본 소리 넣기
2. 버튼에 `UIButtonFeedback` 붙이기 (이 버튼만 다른 소리는 Click Sound 칸에)
3. 판넬에 `UIPanelFeedback` 붙이기, 닫기 버튼 On Click → `UIPanelFeedback.Close`
4. Button이 아닌 것(XR 버튼 등)은 그 이벤트에 `UIButtonFeedback.Play` 연결

- 멈춤(`timeScale = 0`) 중에도 효과가 움직임 (unscaled time)
- World Space UI는 파티클 크기를 Effect Scale 0.2~0.5로

## 안 될 때
| 증상 | 확인 |
|---|---|
| 소리 없음 | Click Sound 칸, Master Volume, 카메라에 AudioListener |
| 반응 없음 | Button Interactable ✅, 같은 오브젝트에 Button이 있는지 |
| 소리가 두 번 | 기능 스크립트에 남은 소리 코드 지우기 |
