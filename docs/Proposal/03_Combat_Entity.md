# 03. 투구 · 개체 상세 기획서 (공 · 핀 · 판정 연출)

> 문서 세트: [목차](Proposal.md) · [01 컨셉](01_Concept.md) · [02 시스템](02_System.md) · **03 투구·개체** · [04 레벨 디자인](04_LevelDesign.md) · [05 밸런스](05_Balance.md)
> 볼링에는 "전투"가 없어서, 가이드의 전투 문서 자리에 **핵심 조작(투구)과 상호작용 개체(공 · 핀)**의 명세를 담았어요.

---

## 1. VR 조작 방식
| 동작 | 컨트롤러 | 판정 |
|---|---|---|
| 공 잡기 | 공에 손을 대고 그립 | `XRGrabInteractable` 선택 시작 |
| 던지기 | 팔을 휘두르며 그립 놓기 | 놓는 순간 손의 속도 · 방향이 공에 전달, 소켓에서 0.5m 이상 떨어져야 투구 |
| 내려놓기 | 소켓 근처(0.5m 안)에서 놓기 | 제자리로 돌아감 |
| 버튼 누르기 | 레이로 가리키고 트리거 | 게임 시작 · NEXT · ⏸ 등 |
| 이동 | 텔레포트 (XR 템플릿) | 레인 앞 자리 이동 |

| VR 편의 | 설계 |
|---|---|
| UI | 점수판 · 레벨 · 판정 글자 캔버스가 **헤드셋을 따라옴** → 고개를 돌려도 보임 |
| 멀미 | 기본은 제자리 플레이, 이동은 텔레포트만 → 연속 이동으로 인한 멀미 없음 |
| 피드백 | 시각(떠오르는 숫자 · 파티클) + 청각(핀 · 굴러감 · 판정 소리) 이중 피드백 |

## 2. 공 명세 (`Ball`)
| 항목 | 값 |
|---|---|
| 물리 | Rigidbody + XR 잡기, 놓을 때 손 속도 그대로 |
| 보관대 | 소켓 4칸, 던지면 0.5초 뒤 같은 칸에 새 공 (오브젝트 풀) |
| 종류 | 프리팹 여러 개 중 랜덤 (색 · 무늬) |
| 회수 | 손에서 놓은 뒤 30초 / 소켓에서 30m / 높이 -10 아래 |
| 소리 | 던진 뒤 바닥에 처음 닿을 때 굴러가는 소리 1번 |
| 💡 제안 | 무게 3종 (가벼움: 빠르지만 핀 덜 튐 / 무거움: 느리지만 잘 쓰러뜨림) — 레벨 6부터 선택 |

## 3. 핀 명세 (`Pin`)
| 항목 | 값 |
|---|---|
| 세트 | 레인당 10개 × 4레인 (`PinSpawner`가 바닥 면에 정확히 맞춰 생성) |
| 대기 상태 | 고정(kinematic) — 공(0.2m/s 초과)이나 움직이는 핀이 핀 크기 + 0.05m 안에 오면 물리 켬 |
| 쓰러짐 판정 | Floor 태그에 닿음 **또는** 45도 이상 기울어짐 |
| 점수 | 쓰러질 때 +100 (1번만) |
| 다시 세우기 | 처음 자리 · 방향으로 되돌리고 다시 고정, 세우는 소리 |

## 4. 판정 문구 명세
| 문구 | 조건 | 색 · 연출 | 소리 | 이펙트 |
|---|---|---|---|---|
| `LEVEL n` | 레벨 시작 | 톡 튀어나와 페이드 | – | – |
| `ONE MORE!` | 1개 이상 · 목표 전 · 레벨당 3번까지 | 톡 튀어나옴 (1.6배 → 1배) | ONE MORE 소리 | 맞힌 레인 위 파티클 |
| `MISS` | 0개, 또는 30초 초과 | 〃 | MISS 소리 | 맞힌 레인 위 파티클 |
| `NICE JOB!` | 목표 점수 도달 | 〃 | NICE JOB 소리 | – |
| `FAIL` | 기회 0 · 목표 미달 (마지막이 MISS면 생략) | 〃 | FAIL 소리 | – |
| `5 pin` | 레인마다 쓰러진 개수 | 쓰러지는 대로 올라감 | – | – |
| 남은 시간 | 맞힌 레인에만 (처음엔 4개 모두) | 숫자 | – | – |

### 💡 제안 — 추가 판정
| 문구 | 조건 | 보상 |
|---|---|---|
| `STRIKE!` | 한 번에 한 레인 10핀 | +500 보너스 · 조명 전체 번쩍 · 기회 소모 없음 |
| `ON BEAT!` | 노래 박자 ±0.15초 안에 놓음 | 이번 투구 점수 × 1.2 |
