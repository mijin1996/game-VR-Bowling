# 코드 구조

게임 스크립트는 `Assets/cs/` 안에 기능별 폴더로 나눠 두었어요.

## 1. 스크립트 지도 (`Assets/cs/` 폴더별)
| 폴더 | 파일 | 하는 일 |
|---|---|---|
| `Manager/` | `GameManager` | 점수 (+100, 점수 글자, 떠오르는 숫자) |
| | `LevelManager` | 레벨·목표 점수·기회·투구 판정·30초 제한 |
| | `ButtonManager` | 화면 표시(레벨 글자, 팝업, 판넬, 랭킹, 멈춤) + 버튼 클릭 |
| | `SoundManager` | BGM, 노래 목록, 효과음 |
| `Pin/` | `Pin`, `PinSpawner` | 핀 하나(고정·풀림·쓰러짐) / 핀 세트 배치, 레인별 쓰러진 개수 |
| `Ball/` | `Ball`, `BallSpawner` | 공 하나(잡기·던지기·회수) / 소켓 채우기, 공 창고(재사용) |
| `Common/` | `Spawner<T>` | 프리팹 고르기·만들기 공통 부모 (PinSpawner, BallSpawner) |
| `Interface/` | `ISpawner`, `IReset`, `ITextPopEffect` | "다시 깔 수 있다" / "처음 상태로" / "톡 효과" 약속 |
| `Ranking/` | `Ranking`, `RankingBoard` | PlayerPrefs + JSON 저장(10위) / 랭킹판 칸 채우기 |
| `UI/` | `LevelClearUI`, `PauseMenuUI`, `SongListUI` | 버튼이 눌렸다고 알리기만 함 (다른 게임에 재사용) |
| `Effect/` | `EffectPop`, `EffectPanelOpen`, `EffectButtonPress`, `EffectNumFlying`, `CountUpBehavior` | 글자 톡, 판넬 열림, 버튼 눌림, 떠오르는 숫자 |
| `Music/` | `BeatSageLights` (사용 중), `rhthem` (꺼 둠) | 천장 조명 깜빡이기 — **둘 중 하나만** 켜기 |

## 2. 흐름
```
공 던짐   Ball ─Thrown→ BallSpawner ─BallThrown→ LevelManager (판정 시작), 0.5초 뒤 빈 소켓 채움
핀 쓰러짐 Pin ─OnPinFallen→ GameManager ─ScoreChanged→ LevelManager
                               └ 점수 글자 톡 + 떠오르는 숫자
판정 끝   LevelManager → ButtonManager (팝업·판넬) / Pin.ResetAllPins() / Ranking.Save()
버튼      판넬·멈춤 버튼 → LevelClearUI·PauseMenuUI → ButtonManager → LevelManager
          노래 버튼 → SongListUI → SoundManager.PlaySong(번호)
```

## 3. 사용한 패턴
| 패턴 | 어디서 |
|---|---|
| 싱글톤 | GameManager, SoundManager, ButtonManager |
| 옵저버(C# 이벤트 / UnityEvent) | Ball·BallSpawner·GameManager·SoundManager 알림 / UI 프리팹 버튼 |
| 템플릿 메서드 + 제네릭 | `Spawner<T>` → PinSpawner, BallSpawner |
| 오브젝트 풀 | BallSpawner 공 창고 `Queue<Ball>` |
| 전략(인터페이스) | `ITextPopEffect`, `IFloatingBehavior` |
| 레지스트리 | `Pin.allPins` — 모든 핀을 한 번에 세기·세우기 |

## 4. 아쉬운 점 (다음에 고칠 거리)
- `ButtonManager`, `LevelManager`가 하는 일이 많음 (단일 책임 △)
- 상위 로직이 싱글톤을 직접 부름 (의존 역전 ✕)
- 판정 결과가 `if / else if` 사슬 → 결과 표(데이터)로 빼면 새 결과를 추가하기 쉬움
- `Pin.FixedUpdate`의 `Physics.OverlapSphere`가 매 물리 프레임 배열을 새로 만듦 → `OverlapSphereNonAlloc` 추천 (Quest GC 끊김)
- 효과 파티클은 프리팹이 스스로 지워지는 설정(`Clear Behavior: Destroy`)인지 꼭 확인
